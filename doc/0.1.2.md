Track refunds alongside expenses, review their shared history, and edit saved transaction details with a refreshed interface.

## Expenses and refunds

- Create expense and refund cards using a compact rounded selector, with a sliding highlight that changes between red and green.
- Record refunds independently or optionally link them to an existing expense, including multiple partial refunds.
- See separate transactions for each payment and refund, with direction icons, type labels, and red expense or green refund amounts.
- Refunds reduce net spending and restore the remaining budget when one is set. Without a budget, Dashboard and Analysis show net spending or net refunds.
- Count refunds on the date received, including refunds received in a later month than the original payment.

## Linked history and editing

- Open an expense or any linked refund to see the original expense and its refund cards together.
- Edit a saved expense's title, description, category, and amount.
- Add more refund cards from the history view; additional expense cards cannot be added there, and transaction types stay fixed.
- New refund cards inherit the expense's currently edited title and category.
- Selectable refund dates appear in green, while the original expense date stays locked and muted.
- Deleting an expense with linked refunds removes the group after confirmation; deleting a refund removes only that refund.

## Speech review improvements

- Updated Qwen's extraction prompt with English and Hinglish examples for both expenses and refunds.
- Added explicit instructions to preserve description details such as merchants, quantities, payment methods, purpose, and refund reasons when stated.
- Review extracted transactions with descriptions and distinct expense/refund icons before creating cards. Their type and description carry through to the editable cards.

## Interface improvements

- Refreshed the shared date picker with a selected-date heading, rounded controls, a green selected day, and **Today**, **Cancel**, and **Apply** actions.
- Reduced extra space around card dates and added the selected category's icon inside its field.
- Dropdown menus now match their input box's width.
- Renamed the daily transaction list heading to **Transactions**.
- The expense/refund slider respects reduced-motion settings.

## Compatibility and setup

- Existing expenses remain expenses when updating; saved data and budgets are preserved.
- Nearby sharing now preserves refund types and optional expense links. Update both phones to v0.1.2 or later before sharing refunds.
- Fixed Android SDK package installation compatibility with the newer Android CLI and added setuptools preparation for the Python 3.12 QAIRT converter.
